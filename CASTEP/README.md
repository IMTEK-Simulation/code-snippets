Snippets for use with CASTEP output.

data.sh: give the [Seedname].castep ascii output of a CASTEP geometry optimizytion run as an argument and obtain three data files SRelax.dat, FRelax.dat, and ERelax.dat that hold the maximum stress, the maximum force and the energy. There are also three data files a.dat, b.dat, and c.dat that contain the lattice parameters and their change with iterations.

Relax.py plots these six values in viewgraphs.
